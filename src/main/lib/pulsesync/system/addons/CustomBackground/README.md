# Custom Background

Стильный аддон для Яндекс Музыки, который заменяет глобальный фон приложения и фон блока «Моя волна» на выбранное изображение, видео или обложку текущего трека.

## Особенности

- **Два режима фона**: установите собственное изображение/видео для всего приложения и отдельно для раздела «Моя волна» или включите адаптивный режим, синхронизирующий фон с обложкой играющего трека.
- **Поддержка форматов**: статичные изображения (JPG, PNG, WEBP), живые обои (GIF, MP4, WEBM). Медиафайлы сохраняются локально для мгновенной загрузки.
- **Продвинутый поиск обложек**: автоматически определяет обложку трека как на старой, так и на новой версии страницы «Моя волна», исключая фото артистов и мелкие иконки.
- **Кроссфейд‑переходы**: плавная смена фона при переключении трека или сворачивании/разворачивании приложения.
- **Тонкая настройка**: раздельные ползунки яркости, размытия и пикселизации для глобального фона и фона «Моей волны», а также возможность добавить виньетку.
- **Режим совместимости**: встроенная кнопка «Новая волна» для переключения между новым и старым дизайном страницы «Моя волна».

## Использование

1. В верхней панели приложения появится кнопка с иконкой фонов (рядом с системными кнопками).
2. Нажмите на неё — откроется меню с пунктами:
   - **Глобальный фон** — установить фон для всего приложения.
   - **Фон Волны** — установить фон только в разделе «Моя волна».
   - **Адаптивный фон** / **Адаптивная волна** — включить автоматическую синхронизацию с обложкой текущего трека.
3. Чтобы сбросить любой из фонов, нажмите значок ↻ рядом с соответствующим пунктом.
4. Все дополнительные настройки (яркость, размытие, пикселизация, виньетка) находятся в настройках аддона **Custom Background** внутри Pulse Sync.
