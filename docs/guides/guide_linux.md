# Руководство по установке YaMusicMod для Linux

## ◈ Содержимое архива:

- `app.asar` — модифицированное ядро Яндекс Музыки (со встроенными плагинами, настройками и улучшениями).
- `guide.md` — данная инструкция.

---

## ▷ Установка за 1 минуту:

1. **Закройте Яндекс Музыку**, если она запущена:

    ```bash
    killall yandex-music || true
    ```

2. **Создайте резервную копию оригинального файла** (рекомендуется):

    ```bash
    sudo cp "/opt/Яндекс Музыка/resources/app.asar" "/opt/Яндекс Музыка/resources/app.asar.bak"
    ```

3. **Скопируйте модифицированный `app.asar`**:

    ```bash
    sudo cp app.asar "/opt/Яндекс Музыка/resources/app.asar"
    ```

    _(Если приложение установлено через Flatpak или AUR, путь может быть `~/.local/share/...` или `/usr/lib/yandex-music/resources/app.asar`)._

4. **Запустите Яндекс Музыку** — все плагины и функции активны!

---

## ⟲ Удаление мода (откат к оригиналу):

```bash
sudo cp "/opt/Яндекс Музыка/resources/app.asar.bak" "/opt/Яндекс Музыка/resources/app.asar"
```
