# YaMusicMod v1.34.2 ♡

Обновление модификации для настольного приложения Яндекс Музыка (Linux, Windows, macOS).

---

### ✦ Что нового в v1.34.2:

- **Обновление мода прямо в приложении (1-Click In-App Update)**:
    - При выходе новой версии мода появляется аккуратное уведомление: `Доступно обновление мода <версия> -> <новая_версия>`.
    - Кнопка **«Скачать»** загружает актуальный `app.asar` прямо внутри приложения с отображением прогресс-бара.
    - После скачивания кнопка меняется на **«Установить»** — мод автоматически заменяет файл ядра и перезапускает Яндекс Музыку:
        - **Linux**: автоматическая замена через Polkit (`pkexec`) при необходимости root-прав или напрямую в пользовательских каталогах.
        - **Windows**: фоновое безопасное обновление при закрытии процесса без блокировки файлов и мгновенный перезапуск.
        - **macOS**: обновление внутри пакета приложения с сохранением прав доступа.
- **Отключение навязчивых уведомлений официального обновления**:
    - Полностью отключены системные уведомления официального клиента (например, `Доступна версия 5.122.0`) и фоновая загрузка официальных пакетов, перезаписывавших мод.
- **Интеграция горячих клавиш перезагрузки**:
    - Перезагрузка страницы по `F5` / `Ctrl+R` теперь происходит бесшовно и не приводит к случайному закрытию окна.
- **Автоматизация отслеживания апстрима**:
    - Добавлен GitHub Actions воркфлоу для регулярного отслеживания новых версий официальной Яндекс Музыки.
- **Чистый стиль оформления**:
    - Все описания, скрипты и документация избавлены от цветных эмодзи в пользу лаконичных контурных символов (`♡`, `◈`, `▷`, `✦`, `✓`).

> [!NOTE]
> **О мобильных устройствах (Android / iOS):**
> Мобильные приложения Яндекс Музыки являются нативными бинарными приложениями (Kotlin / Swift), не используют движок Electron и не содержат файл `app.asar`. Данный мод предназначен для настольных ОС (Linux, Windows, macOS).
