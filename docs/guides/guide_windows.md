# Руководство по установке YaMusicMod для Windows

## 📦 Содержимое архива:
- `app.asar` — модифицированное ядро Яндекс Музыки (со встроенными плагинами, настройками и улучшениями).
- `guide.md` — данная инструкция.

---

## 🚀 Установка за 1 минуту:

1. **Полностью закройте Яндекс Музыку**:
   - Закройте окно приложения.
   - Проверьте трей (возле часов): если иконка Яндекс Музыки там есть, нажмите правой кнопкой мыши -> **Выход**.
   - При необходимости завершите процесс `YandexMusic.exe` в Диспетчере задач.

2. **Откройте папку ресурсов приложения**:
   - Нажмите сочетание клавиш **Win + R** на клавиатуре.
   - Вставьте путь:
     ```text
     %LOCALAPPDATA%\Programs\YandexMusic\resources
     ```
   - Нажмите **Enter** (ОК).
   *(Обычно это папка: `C:\Users\<ВашеИмя>\AppData\Local\Programs\YandexMusic\resources`).*

3. **Сделайте резервную копию оригинала**:
   - Переименуйте исходный файл `app.asar` в `app.asar.bak`.

4. **Скопируйте новый `app.asar`**:
   - Перетащите файл `app.asar` из этого zip-архива в открытую папку `resources`.

5. **Запустите Яндекс Музыку** — мод готов к работе!

---

## 🔄 Удаление мода (откат к оригиналу):
Удалите `app.asar` и переименуйте `app.asar.bak` обратно в `app.asar`.
